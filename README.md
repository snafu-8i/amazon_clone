# 🛒 Clone Amazon — Site Web Responsive (Frontend Only)

Bienvenue dans ce projet de clone d’Amazon, entièrement développé en HTML, CSS et JavaScript.
Ce site reproduit plusieurs fonctionnalités clés du géant du e-commerce, tout en restant un projet purement frontend, sans aucune opération réelle en back-end.

## 🚀 Fonctionnalités

### 🏠 Page d’accueil

• *Présentation des produits phares*

• *Carrousel / sections thématiques*

• *Adaptation parfaite à tous les écrans (PC, tablette, smartphone)*

### ⚡ Page des Ventes Flash

• *Liste de produits avec réductions*

• *Mise en avant visuelle des promotions*

• *Ajout rapide au panier*

### 🧺 Panier complet et interactif

• *Ajout d’articles*

• *Retrait d’articles*

• *Mise à jour automatique des quantités*

• *Calcul du prix total en temps réel*

• *Affichage dynamique du nombre d’articles*

• *Stockage local*

### 📱 Responsive Design

Le site a été conçu pour offrir une expérience fluide sur n’importe quel appareil :

• *Grilles flexibles*

• *Layouts plus compacts sur mobile*

• *Menus adaptés*

• *Images et composants redimensionnables*

• *Chaque page a été pensée pour rester claire, lisible et ergonomique qu’importe la taille d’écran.*

### 🛠️ Technologies utilisées

• *HTML5*

• *CSS3 (Flexbox, Grid, responsive design)*

• *JavaScript Vanilla*

• *Assets statiques (images, icônes, placeholders)*

### 🛑 Important : Projet Frontend • Aucun Vrai Back-End

Ce site est un clone visuel et fonctionnel d’Amazon, créé à des fins :

• d’Apprentissage

• de Démonstration

• d’Expérimentation

Il ne réalise aucune transaction, ne se connecte à aucun serveur, et aucune donnée personnelle n’est collectée.

Toutes les fonctionnalités reposent exclusivement sur le JavaScript côté client.

⚠️**Il ne s’agit pas d’un site commercial ni d’une copie destinée à un usage réel.
Ce projet ne revendique aucune affiliation avec Amazon.**
